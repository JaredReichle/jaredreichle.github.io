# Jared Reichle - Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. This website showcases professional experience, projects, and provides a way for visitors to get in touch.

## Sections

1. **About Me Section**: Eye-catching introduction with call-to-action buttons
2. **About Me**: Personal information, skills, and statistics
3. **Resume**: Professional experience, education, and certifications
4. **Projects**: Portfolio of work with filtering capabilities
5. **Contact**: Contact information and contact form
